# Etsy listing rules (digital products)

## Hard limits
- Title: max 140 characters. Put the strongest buyer keyword in the first 40.
- Tags: exactly 13, each max 20 characters. No duplicates, no punctuation beyond hyphens.
- Taxonomy: `343` (Guides & How Tos) for manuals, guides and how-to downloads.
- Listing type: `download` / digital. Quantity is effectively unlimited.

## Title hygiene
- One `&` only; replace further ones with "and".
- No `%` or `:` characters — Etsy rejects some encodings.
- No newlines, no repeated keyword stuffing.

## Tags
- Prefer 2–3 word buyer phrases over single generic words.
- Pull from `keyword_evidence` returned by the scan, weighted by estimated sales.
- Keep the model code or year range in at least two tags when the niche is model-specific.

## Description structure
1. One-line promise naming the exact model/variant.
2. What's included (file count, format, page count only if known).
3. File format and how delivery works (instant download after purchase).
4. Who it's for.
5. Terms: personal use, no physical item shipped.

## Never
- Copy competitor wording.
- Invent model numbers, page counts, brands or compatibility.
- Publish a digital listing before the file is attached in Shop Manager.
